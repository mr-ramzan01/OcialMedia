# Ocial Media – Client

React 18 + Material UI 9 front end. See the [root README](../README.md) for full setup.

```bash
npm install
npm start        # http://localhost:3000 (uses .env.development -> REACT_APP_API_URL=http://localhost:8080)
npm run build    # production bundle in ./build
```

Configuration lives in `.env.development`, `.env.production` and `.env.example`.
